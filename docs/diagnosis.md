# Диагностика пилота PPO

Пилот с коэффициентом энтропии 0,01 завершил 1 000 000 переходов. В 1 000 завершённых обучающих эпизодах достижений цели не зарегистрировано. На всех 20 проверках валидации успешность составляла 0 из 20. Контрольная точка, выбранная по средней награде, относится к шагу 563 200; её успешность на валидации также равна нулю. Начальное стандартное отклонение гауссовской политики равно 1, в финальной контрольной точке — 0,0017925. Потери оставались конечными; шесть пройденных тестов проверяют свойства реализации, но не доказывают, что политика научилась решать задачу.

Возможные причины для дальнейшей проверки — сокращение разброса действий и недостаточная согласованность независимо выбираемых действий во времени. Результаты согласуются с этими гипотезами, но не устанавливают единственную причину; подтверждённой математической ошибки PPO по этим данным не выявлено.

Отдельный диагностический опыт без обучения и изменения награды использовал 40 seed среды 10000–10039 и независимый генератор с seed среды плюс 50000. Действие выбиралось из нормального распределения со средним 0 и стандартным отклонением 1, ограничивалось диапазоном [-1, 1] и удерживалось указанное число шагов исходной среды:

| Время удержания | Успехов | Средняя награда |
| --- | ---: | ---: |
| 1 шаг | 0/40 | −51,1293774 |
| 20 шагов | 39/40 | 80,908036 |
| 50 шагов | 39/40 | 81,697414 |

Это сравнение характеризует исследование, а не обученную политику PPO. [Исходные измерения](../results/diagnosis/exploration_probe.json) сохранены для всех эпизодов. Для контекста: [конфигурация RL Baselines3 Zoo](https://raw.githubusercontent.com/DLR-RM/rl-baselines3-zoo/master/hyperparams/ppo.yml) для MountainCarContinuous использует, среди прочего, SDE, нормализацию и γ = 0,9999; это не гарантирует успех в данном проекте.

Запланированные пилоты с меньшей энтропией и пять финальных запусков приостановлены и не начаты. Следующий разумный шаг — ограниченный новый пилот, проверяющий исследование: сначала добиться достижения цели во время обучения и успешной детерминированной валидации, затем оценить устойчивость на нескольких seed. Основной код в рамках этой диагностики не менялся; задача обучения пока не решена.
